1 · Google setup

One-time step. Create a Web application OAuth client in Google Cloud Console and add this origin as an authorised JavaScript origin. Show me how

  1. Open Google Cloud Console and create (or pick) a project.
  2. APIs & Services → Library → enable Google Calendar API.
  3. APIs & Services → OAuth consent screen → External → fill the basics → add your own email under Test users.
  4. Credentials → Create credentials → OAuth client ID → type Web application.
  5. Under Authorised JavaScript origins add this origin. Leave redirect URIs empty.
  6. Copy the Client ID into the box above. Nothing leaves your browser — it is stored in localStorage.
